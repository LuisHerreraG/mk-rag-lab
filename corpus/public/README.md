# corpus/public

Material **público** únicamente: documentación open source, artículos propios ya
publicados, especificaciones públicas.

Nunca entra aquí: nada del empleador, nada de `corpus/private/`, nada con datos de
clientes, rutas internas, IPs o capturas. Si un documento no podría estar en un repo
público, no va en esta carpeta.

Formato: `.md` o `.txt`. Un archivo = un documento; el encabezado de nivel 1 se usa
como ancla de cita.
